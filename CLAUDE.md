# CLAUDE.md — «Караван идёт»

Авторский сайт о кино Карена Аванесяна. Этот файл — источник правды по
**единым стандартам контента и оформления**. Любая сессия, редактирующая
репозиторий, обязана им следовать, чтобы страницы оставались консистентными.

## Архитектура (коротко)
- Статический сайт. SPA-оболочка `index.html` (весь CSS и роутер тут) +
  общий модуль рендера `assets/render.js` (используется И сборщиком, И
  браузером — поэтому функции в нём чистые, без обращения к DOM на верхнем уровне).
- Сборка: `npm run build` → `build.mjs` пререндерит каждую страницу в `dist/`
  (плюс sitemap, rss, robots). `dist/` в `.gitignore` — **не коммитим**.
- Деплой: Netlify собирает из `main` → https://www.karavancinema.com (канонический
  домен, `SITE` в `build.mjs`); https://karavancinema.netlify.app — техническое зеркало.
- Контент: markdown + JSON-манифесты:
  `reviews/` (рецензии), `collections/` (подборки), `feed/` (заметки),
  `festivals/`, `press.json`. Картинки берутся с TMDB и «запекаются» локально
  (`tools/`, токен в `.env`).
- Темы: **тёмная — по умолчанию** (`:root`), светлая — `:root[data-theme="light"]`.
  Переключатель «солнце/луна» в шапке, выбор в localStorage. Скролл-истории
  следуют теме.

## Рабочий процесс
- После правок контента/рендера: `npm run build`, проверить, закоммитить
  **только изменённые файлы** (часто есть параллельная работа в `lectures/` от
  другой сессии — её не трогаем), затем `git push` (Netlify задеплоит).
- Коммитить/пушить только по явной просьбе. Сообщения — на русском, в стиле
  существующей истории.

## СТАНДАРТ КОНТЕНТА

### 1. Оценки фильмов
- **Единая шкала: 0–10** (допустимы половинки: 7.5). Хранится как `rating: 8`.
- **Три формы показа, и только они:**
  - бейдж на постере (карточки, featured): `★ N` — `ratingHTML(rating)` в render.js.
  - страница рецензии: инлайн в строке метаданных (год · реж · страна) —
    `<span class="rate">★ N/10</span>` (одна звезда + число, как в скролл-историях).
  - инлайн в подборках/заметках: `<span class="rate">★ N/10</span>` (в строке метаданных).
- **Запрещено:** рисовать звёзды вручную с инлайн-цветом, использовать шкалу /5.
  Звёзды/`.rate` — латунные (`--gold`), пустые — `--gold-empty`, тема — автоматически.

### 2. Названия фильмов
Три поля, у каждого одна роль:
- `film` — **русское прокатное название в «ёлочках»**, и больше ничего.
  Без скобок, без оригинала внутри. ✅ `«Сообщите матери»` ❌ `«Сообщите матери» (Amma Ariyan)`
- `original` — оригинальное название. Порядок: **родное письмо → латиница/англ.**
  через ` / `. Для русских/советских фильмов — опускаем.
  ✅ `姿三四郎 / Sanshiro Sugata` · `어쩔수가없다 / No Other Choice`
- `title` (только рецензии) — **заголовок-эссе** (фраза, а не имя фильма).
  ✅ `Дебют Куросавы возвращается целым`
- Показ везде одинаковый: **«Русское»**, оригинал — вторичной строкой (приглушённо/латунь).
  Никогда не склеивать русское и оригинал в одно поле.

### 3. Подборки и скролл-истории (`layout: scrolly`)
Front-matter: `title`, `subtitle`, `kicker`, `cover`, `layout: scrolly`,
`kind: films|characters`, опционально `snap: page`, `media: stills`, `overline`.
- `kind: films` (нуар, молодёжь): запись — `<h3>` = **«Русское название»**,
  золотая строка-подпись = **оригинал**.
- `kind: characters` (женские персонажи): `<h3>` = **имя персонажа**,
  золотая строка-подпись = **«Русское название»**.
- Строка метаданных: `год · реж. Режиссёр · [страна | в гл. роли Актриса] · оценка · Letterboxd`.
- Обложка подборки (`cover`): **культовый кадр** из фильма (textless backdrop с TMDB),
  не постер с обрезанным текстом.
- **Первый слайд (стандарт), сверху вниз:** рубрика **«Скролл-история»** (латунь,
  капитель) → круглое фото автора → «рассказывает **Карен Аванесян**». Поэтому в
  `kicker` рубрику НЕ дублируем — там только описание истории (или пусто).
- `overline` (например `Film Noir`) — латунный префикс В ОДНОЙ СТРОКЕ с названием
  (`Film Noir: Тёмная дюжина`), и на карточке, и на слайде; не отдельной строкой.
- История про один фильм: в front-matter даём `director`, `year`, `rating`,
  `letterboxd` — на первом слайде под названием выводится одна строка
  метаданных: `режиссёр · год · ★ N/10 · Letterboxd`. Отдельный вводный
  «слайд-дубль» не делаем — вводный текст кладём в `subtitle`.
- Заметки-сцены: заголовок мысли — в `<h3>`, без служебных строк «Заметка N».

### 4. Letterboxd
- Ссылка строится как `https://letterboxd.com/tmdb/<tmdb_id>`.
- **Единый вид везде — пустой `<a class="lb">` (три фирменные точки фоном).**
  Никаких подписей «Letterboxd», стрелок ↗, рамок-кнопок и инлайн-SVG —
  иначе логотип задваивается (фон-точки + вставленный SVG).
  ✅ `<a class="lb" href="…" target="_blank" rel="noopener" aria-label="Letterboxd"></a>`
- В подборках/заметках — на строке метаданных. На странице рецензии — та же
  иконка, крупнее (через `.ext-links .lb`).

### 5. Постеры / кадры
- Постеры — TMDB, размер `w500` для карточек/сцен, `w780`/`w1280` для обложек.
  Локализуются сборкой. Без «киноплёнки» по краям.
- Язык постера — оригинальный язык фильма (см. правило в памяти проекта).

### 6. Визуальные токены (не хардкодить цвета для темизируемого)
- `--gold` — декор (звёзды, капитель-лейблы, линейки, «ИДЁТ»).
- `--accent` — только интерактив (ссылки, активный пункт, «Читать →»).
- Светлая тема: бумага `--bg`, чернила `--text`, лазурные шапка/футер,
  тёплые границы `--border`. Тёмная — кинематографичная, золото на тёмном.

## Чек-лист при добавлении контента
- [ ] `film` = только «Русское»; оригинал — в `original` (родное → латиница).
- [ ] `rating` — число 0–10; оценка показана общим компонентом, не вручную.
- [ ] Letterboxd — `letterboxd.com/tmdb/<id>`, иконка `.lb` на строке метаданных.
- [ ] Постер/обложка — TMDB, запекается сборкой; обложка подборки = кадр, не постер.
- [ ] Цвета берутся из токенов (`--gold`/`--accent`), не хардкодятся.
- [ ] `npm run build` проходит; коммит — только изменённые файлы.

## Обновление (июль 2026): связность сайта

- Данные курсов вынесены в `tools/courses-data.mjs` (единый источник для лендинга `/lectures/`, карточек на главной и «мостов» фильм→лекция). Публикация лекции = `ready:true` там.
- `build.mjs` перед рендером обогащает рецензии: `mins` (слова/180), `tags` (из frontmatter), `bridge` (по совпадению названия фильма со строками `films` курсов), `incollections` (фильм упомянут в тексте опубликованной подборки), `related` (метки ×2 + режиссёр ×3 + фестиваль ×1, топ-3). Обогащённый манифест пишется в `dist/reviews/manifest.json`; сводка курсов и счётчики — в `dist/site-data.json`. SPA берёт extras оттуда же.
- Новые маршруты: `/search` (клиентский поиск) и `/tag/<translit-slug>` (генерируются в `build.mjs`; транслит — `tagSlug` в `render.js`).
- Даты рецензий: поле `date` (ISO) в `reviews/manifest.json`; у заметок — `dateISO` рядом с человекочитаемой. RSS сортируется по датам и ставит `pubDate`.
- Тумблер светлой темы закомментирован в `index.html` (маркер «Тумблер светлой темы временно скрыт»); JS-обработчик под страховкой `if(themeToggle)`.
- `npm run bake` (`tools/bake-images.mjs`) — одноразовая запечка TMDB-картинок в `assets/img/` с переписыванием исходников. Идемпотентен, при 403 честно оставляет внешние ссылки.
- Лендинг `/lectures/` — в токенах сайта; акценты курсов через классы `acc-mrx / acc-vie / acc-soc` (номер лекции, клин у h2, кикер, ховеры). Карточки курсов на главной: три в ряд, поля `kicker/tagline/accent` из `courses-data.mjs`.
- Закреп «Выбор автора»: пустой `featured` в `site.json` = блока нет. Ряд «Кинофестивали» на главной удалён из `homeView` (страница `/festivals` живёт). Дата+минуты рецензии — после `.prose` (`pubLine`), фестиваль — `.fest-stamp`.
- Указатель фильмов собирает и скролл-истории/заметки: build парсит в feed-md `alt="… кадр из фильма «Название»"` → карточка «Скролл-история» на хабе фильма. Поэтому в alt кадров заметок всегда пишем «— кадр из фильма «Русское название»».
- Публикация в СМИ может описывать несколько фильмов: `films: ["«…»", …]` в `press.json` (одиночное `film` тоже живо). «Прокат 2026» на главной = рецензии с тегом `прокат2026` + press с `prokat:true` + ручной список `prokat: […]` в `site.json` (дедуп по слагу).
- Со страницы рецензии на хаб фильма ведёт `.film-hub-line` («Все материалы о фильме →», ставится автоматически). RSS-иконка из шапки убрана (лента и футер живы).
- Фестивальный дневник (`diary/`): один файл = один фестиваль, страница-лента
  `/diary/<slug>` (сейчас `venice-2026`). День пишется двумя строками markdown —
  `## День 3 · 29 августа` и `### Заголовок`, всё до следующего `##` попадает в
  тело дня; `diaryEntries` в `render.js` разбирает уже готовый HTML, поэтому
  руками размечать ничего не нужно. У каждого дня свой якорь `#den-N` —
  строка-маркер сама является постоянной ссылкой на этот пост.
  День может состоять из нескольких фильмов — каждый под своим `###` вида
  `«Русское название» (Original), Режиссёр`, под каждым кадр; для закрепа
  заголовки склеиваются через « · ».
  Превью для соцсетей (`og:image`) дневника — первый кадр свежего дня
  (`firstImage` в `build.mjs`), `cover` во front-matter не нужен.
  `pinned: true` в `diary/manifest.json` = блок-закреп первым на главной
  (`diaryPinHTML`, последние 3 дня); сводка считается из markdown и кладётся в
  `dist/site-data.json`, откуда её берёт и SPA. Свежий день пишем СВЕРХУ файла.
- Прямая ссылка на якорь пререндеренной страницы: `init()` в `index.html`
  доскраливает сам — нативный прыжок сбивается вступительной анимацией `main`,
  а после `load` страница ещё «дорастает» шрифтами и кадрами, поэтому прыжок
  повторяется по `load`.
- «Скрытая ссылка»: `unlisted: true` в манифесте (сейчас — у подборки
  `zolotye-lvy-venecii`). Отличается от `draft: true`: страница **собирается** и
  живёт по прямому адресу, но её нет в `/collections`, на главной, на хабах
  фильмов, строкой «в подборках» на рецензиях, в sitemap — и она отдаётся с
  `<meta name="robots" content="noindex, nofollow">`. Хелперы `isListed/listed`
  в `render.js`, флаг `noindex` в `buildMeta`. Ссылку можно отдать вручную.
- Мультиавторские скролл-истории (пример: `collections/zolotye-lvy-venecii.md`):
  автор сцены — блок `.coll-critic` (крупный круглый портрет + имя + ссылка на
  канал `.critic-tg` с фирменной иконкой телеграма). В markdown он **соседний**
  с `.coll-body`, последним ребёнком `.coll-entry` — тогда флекс кладёт его на
  край, противоположный постеру (чётные сцены зеркалятся, и колонка едет вместе
  с ними). Файлы — `assets/critics/<фамилия>.jpg` (список в
  `assets/critics/README.md`).
  Front-matter `authors: auto` — и первый слайд сам собирает из этих блоков ряд
  кликабельных аватаров (`.scrolly-avatars`); каждый ведёт **к своей сцене**
  (`#scene-N`, id проставляет `scrollyView`), а не в телеграм — ссылка на канал
  и так стоит внутри сцены. Дублировать имена и ссылки во front-matter не нужно.
  `authorsLabel` — подпись под рядом (`**жирное**` становится латунным).
  В подписи автора строка ломается только между «рассказывает» и именем: имя —
  `display:block` + `white-space:nowrap`, а ширина колонки задана вилкой
  `min-width/max-width`, чтобы фамилия не отрывалась от имени.
- Скролл-история на телефоне (медиазапрос `max-width:680px`): постер уходит в
  **полноэкранный фон сцены** (`position:absolute;inset:0;object-fit:cover`,
  `filter:brightness(.6)`), градиент `.coll-entry::after` усилен, текст ложится
  поверх по нижнему краю и выравнивается влево; автор — компактной строкой с
  латунной линейкой сверху. Иначе на узком экране постер мельчает и сцена
  выглядит как список. Там же `scroll-snap-align:start` и мягкий
  (`proximity`) снап — длинный текст выше экрана можно дочитать, а не бороться
  со снапом. Эмблема за текстом на телефоне отключена — кадр и так во весь экран.
  Постер на телефоне поднят (`top:-18%`, низ продолжается под текст): иначе в
  видимой верхней трети экрана — пустой фон над головой героя. Точечно —
  `style="--poster-y:-30%"` на `<img class="coll-poster">` в markdown.
- Якоря на скролл-историях: `scrollToAnchor` в `index.html` на время прыжка
  снимает `scroll-snap` и делает `behavior:'instant'` — mandatory-снап обрывает
  плавную анимацию на первом кадре и утягивает страницу назад, а `'auto'`
  подхватил бы `html{scroll-behavior:smooth}`. Снап возвращается по `rAF`
  (со страховкой `setTimeout`, т.к. в скрытой вкладке `rAF` не приходит).
- Аватары никогда не «пропадают»: `avatarHTML` в `render.js` подставляет через
  `onerror` круглый плейсхолдер с инициалами (`.ph`), а `scrollyView` навешивает
  его и на аватары внутри сцен — в markdown достаточно обычного
  `<img class="critic-avatar" src alt>`. Аватар лежит внутри `.prose`, где общее
  правило `.prose img` даёт скругление 12px и рамку, — поэтому круг задаётся
  селектором `.scrolly .coll-critic .critic-avatar` (иначе портрет становится
  прямоугольным).
- Эмблема истории: front-matter `emblem: /assets/lion.png` → класс
  `scrolly--emblem` и `--emblem` на `main`. На первом слайде это **знак**
  (`.scrolly-emblem`, ~90px, над рубрикой) — силуэт льва упирается во все четыре
  края картинки, поэтому «призрачной» заливкой во весь экран он читается
  прямоугольным пятном, а не львом. На сценах фильмов — фоном за колонкой текста
  (`.coll-body::before`, opacity .09). И там, и там картинка работает как
  CSS-маска и красится `--gold`, поэтому одинаково живёт в обеих темах. Фон
  центруется не по рамке, а по «центру тяжести» силуэта
  (`transform:translate(-38.7%,-51.2%)` для льва) — иначе хвост тянет вправо.
- `count` в `collections/manifest.json`: голое число → бейдж «N фильмов»,
  любая другая строка выводится как есть («6 фильмов · 6 критиков»).
- Скролли: `entry-hero` на `.coll-entry` = одиночная центрированная сцена; `still-wide` на `.coll-poster` = широкий кадр 16:9 единого размера; `art` на `.coll-poster` = живопись/артефакт в боковой сцене (крупнее постера, пропорции сохраняются). Подпись под изображением: обернуть в `<figure class="coll-media">` и добавить `<figcaption class="coll-cap">` — мелкий курсив (пример: feed/kak-troyanskij-kon-potopil-bronzovyj-vek.md).
